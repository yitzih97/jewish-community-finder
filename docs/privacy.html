Privacy Policy — Jewish Community Finder

Last updated: July 23, 2026

Jewish Community Finder is a browser extension that shows nearby shuls, kosher food, Jewish schools, and mikvahs on the map you are already viewing. This policy explains exactly what the extension does and does not do with data.

What we collect

Nothing. The extension has no account, no login, and no analytics or tracking of any kind. We do not collect, store, sell, or share any personal information, browsing history, or usage data. There is no server that belongs to us.

What the extension sends, and to whom

To show places near the map you are viewing, the extension reads the geographic bounds of that map (latitude/longitude) from the page and sends those coordinates to free, public map data services in order to fetch nearby locations:

  • OpenStreetMap (Overpass API and map tiles) — shuls, kosher food, and map previews
  • NCES private-school location service — Jewish schools
  • mikvah.org directory — mikvahs
  • OpenStreetMap Nominatim — converting a typed place name into map bounds when you use the search box

Only map coordinates and, if you use it, the place name you type are sent. No personal identifiers are ever transmitted. Each of these services has its own privacy practices, governed by their respective policies.

Permissions

The extension requests access to the map sites it enhances (such as Zillow and Airbnb) so it can read the visible map area and draw pins on it, and to the map-data hosts listed above so it can fetch places. These permissions are used solely to provide the feature described above.

Data retention

Fetched place results are held only in your browser's memory for the current session to keep the extension responsive, and are discarded when you close the tab. Nothing is written to any external storage.

Contact

Questions about this policy can be directed to the project page at github.com/yitzih97/jewish-community-finder.
